## 1. 시작하기

### 1.1 프로그램 실행

시스템 설치가 완료되면 다음 방법으로 프로그램을 실행할 수 있습니다.

#### Windows
1. `deployment/windows/start.bat` 파일을 더블 클릭합니다.
2. 명령 프롬프트 창이 열리고 서버가 시작됩니다.
3. 웹 브라우저가 자동으로 열리지 않으면, 수동으로 `http://localhost:5173` 주소를 입력하세요.

#### Linux
```bash
# 서버 시작
./deployment/linux/start.sh

# 웹 브라우저에서 접속
# http://localhost:5173
```

### 1.2 첫 화면

프로그램을 실행하면 **대시보드** 화면이 나타납니다.

**화면 구성**:
- **상단 헤더**: 프로그램 제목, 다크 모드 전환 버튼
- **좌측 사이드바**: 메인 메뉴 (프로젝트 목록, 캘린더, 리포트)
- **중앙 영역**: 주요 콘텐츠 표시

### 1.3 메뉴 구조

| 메뉴 | 설명 |
|------|------|
| **홈** | 대시보드 (프로젝트 개요) |
| **프로젝트** | 프로젝트 목록 및 관리 |
| **캘린더** | 통합 일정 캘린더 |
| **리포트** | 진행 현황 및 분석 리포트 |

## 2. 프로젝트 관리

프로젝트는 시스템의 최상위 단위입니다. 각 프로젝트 안에 여러 태스크와 Enabler를 추가할 수 있습니다.

### 2.1 프로젝트 생성

**절차**:
1. 좌측 메뉴에서 **"프로젝트"**를 클릭합니다.
2. 우측 상단의 **"+ 새 프로젝트"** 버튼을 클릭합니다.
3. 프로젝트 정보를 입력합니다:
   - **프로젝트 이름** (필수): 프로젝트 명칭 (예: "신규 시스템 구축")
   - **설명** (선택): 프로젝트 상세 설명
   - **시작일** (필수): 프로젝트 시작 날짜
   - **종료일** (필수): 프로젝트 완료 예정 날짜
   - **상태** (선택): 기본값은 "계획 중"
4. **"저장"** 버튼을 클릭합니다.

**프로젝트 상태**:
- **계획 중** (planning): 프로젝트 계획 단계
- **진행 중** (in_progress): 현재 진행 중인 프로젝트
- **보류** (on_hold): 일시 중단된 프로젝트
- **완료** (completed): 완료된 프로젝트
- **취소** (cancelled): 취소된 프로젝트

### 2.2 프로젝트 조회

**프로젝트 목록 화면**:
- 모든 프로젝트가 카드 형태로 표시됩니다.
- 각 카드에는 프로젝트 이름, 기간, 상태가 표시됩니다.

**검색 및 필터링**:
- **검색창**: 프로젝트 이름이나 설명으로 검색
- **상태 필터**: 특정 상태의 프로젝트만 표시
- **정렬 옵션**: 이름순, 시작일순, 상태순 정렬 가능

### 2.3 프로젝트 수정

**절차**:
1. 프로젝트 목록에서 수정할 프로젝트 카드를 클릭합니다.
2. 프로젝트 상세 화면에서 **"수정"** 버튼을 클릭합니다.
3. 정보를 수정합니다.
4. **"저장"** 버튼을 클릭합니다.

### 2.4 프로젝트 삭제

**절차**:
1. 프로젝트 목록에서 삭제할 프로젝트 카드를 찾습니다.
2. 카드 우측 상단의 **"삭제"** 아이콘을 클릭합니다.
3. 확인 대화상자에서 **"확인"**을 클릭합니다.

**⚠️ 주의**: 프로젝트를 삭제하면 연결된 모든 태스크, Enabler, 의존성도 함께 삭제됩니다. 삭제된 데이터는 복구할 수 없습니다.

## 3. 태스크 관리

태스크는 프로젝트 내의 세부 작업 단위입니다.

### 3.1 태스크 생성

**절차**:
1. 프로젝트 상세 화면으로 이동합니다.
2. **"태스크"** 탭을 클릭합니다.
3. **"+ 새 태스크"** 버튼을 클릭합니다.
4. 태스크 정보를 입력합니다:
   - **태스크 이름** (필수): 작업 명칭 (예: "요구사항 분석")
   - **설명** (선택): 작업 상세 설명
   - **시작일** (필수): 작업 시작 날짜
   - **종료일** (필수): 작업 완료 예정 날짜
   - **기간** (자동 계산): 일수 (예: 10일)
   - **담당자** (선택): 작업 담당자 이름
   - **우선순위** (선택): 낮음, 보통, 높음, 긴급
   - **상태** (선택): 기본값은 "대기 중"
   - **진행률** (선택): 0% ~ 100%
   - **마일스톤** (선택): 중요한 이정표 표시
   - **색상** (선택): 간트 차트에서 표시될 색상
5. **"저장"** 버튼을 클릭합니다.

**태스크 상태**:
- **대기 중** (pending): 시작 전 대기 상태
- **진행 중** (in_progress): 현재 진행 중
- **완료** (completed): 작업 완료
- **보류** (on_hold): 일시 중단
- **차단됨** (blocked): 다른 작업에 의해 차단
- **취소** (cancelled): 작업 취소

**우선순위**:
- **낮음** (low): 일반적인 작업
- **보통** (medium): 표준 우선순위
- **높음** (high): 중요한 작업
- **긴급** (critical): 최우선 작업

### 3.2 태스크 조회

**태스크 목록 화면**:
- 프로젝트의 모든 태스크가 테이블 형태로 표시됩니다.
- 각 행에는 태스크 이름, 기간, 담당자, 우선순위, 상태, 진행률이 표시됩니다.

**진행률 표시**:
- 진행률은 프로그레스 바로 시각화됩니다.
- 0% (빨간색) ~ 100% (초록색)

### 3.3 태스크 수정

프로젝트 수정과 동일한 방식으로 진행합니다.

### 3.4 태스크 삭제

**⚠️ 주의**: 태스크를 삭제하면 연결된 의존성과 Enabler 영향도 함께 삭제됩니다.

## 4. Key Enabler 관리

Key Enabler는 프로젝트 성공을 위해 필요한 핵심 요소입니다 (예: 문서, 승인, 장비, 자원 등).

### 4.1 Enabler란?

**예시**:
- 클라우드 인프라 승인서
- 개발 서버 할당
- 보안 검토 문서
- 데이터베이스 라이선스
- 운영팀 교육 완료

### 4.2 Enabler 생성

**절차**:
1. 프로젝트 상세 화면으로 이동합니다.
2. **"Enablers"** 탭을 클릭합니다.
3. **"+ 새 Enabler"** 버튼을 클릭합니다.
4. Enabler 정보를 입력합니다:
   - **Enabler 이름** (필수): 예) "클라우드 승인서"
   - **설명** (선택): 상세 설명
   - **전달 예정일** (필수): Enabler가 준비될 날짜
   - **담당자** (선택): 책임자 이름
   - **우선순위** (선택)
   - **상태** (선택)
5. **"저장"** 버튼을 클릭합니다.

### 4.3 Enabler와 태스크 연결

Enabler가 특정 태스크에 필요한 경우, 연결 설정을 통해 영향도를 관리할 수 있습니다.

**영향 타입**:
- **차단** (blocking): Enabler가 없으면 태스크 진행 불가
- **필수** (required): 태스크 완료에 필수
- **선택** (optional): 있으면 도움이 됨
- **유용** (helpful): 보조적 역할

**연결 방법** (향후 UI 추가 예정):
현재는 API를 통해 설정 가능합니다. v1.1에서 UI가 추가될 예정입니다.

## 5. 간트 차트 사용법

간트 차트는 프로젝트의 모든 태스크를 시각적으로 표시합니다.

### 5.1 간트 차트 접근

**절차**:
1. 프로젝트 상세 화면으로 이동합니다.
2. **"간트 차트"** 탭을 클릭합니다.

### 5.2 간트 차트 읽는 법

**화면 구성**:
- **왼쪽 영역**: 태스크 목록 (이름, 시작일, 종료일)
- **오른쪽 영역**: 타임라인 (가로 막대로 표시)

**막대 의미**:
- **막대 길이**: 태스크 기간
- **막대 색상**: 태스크 우선순위 또는 사용자 지정 색상
- **막대 내부**: 진행률 표시 (어두운 부분)

### 5.3 간트 차트 조작

**뷰 모드 전환**:
- **일간 뷰**: 일 단위로 상세히 보기
- **주간 뷰**: 주 단위로 보기 (기본값)
- **월간 뷰**: 월 단위로 전체 흐름 보기

**확대/축소**:
- 마우스 휠을 사용하여 줌 인/아웃 가능

**태스크 드래그**:
- 간트 차트에서 태스크 막대를 좌우로 드래그하여 날짜를 조정할 수 있습니다.
- 드래그가 완료되면 자동으로 저장됩니다.

**의존성 화살표**:
- 태스크 간 의존성이 설정된 경우, 화살표로 연결되어 표시됩니다.

### 5.4 간트 차트 익스포트 (향후 추가 예정)

현재 버전에서는 지원하지 않습니다. v1.1에서 PNG/PDF 익스포트 기능이 추가될 예정입니다.

## 6. 의존성 그래프

태스크 간의 의존 관계를 그래프로 시각화합니다.

### 6.1 의존성 그래프 접근

**절차**:
1. 프로젝트 상세 화면으로 이동합니다.
2. **"의존성 그래프"** 탭을 클릭합니다.

### 6.2 그래프 읽는 법

**노드** (원형 또는 사각형):
- 각 노드는 하나의 태스크를 나타냅니다.
- 노드 색상은 태스크 상태를 나타냅니다.

**화살표**:
- 화살표는 태스크 간 의존성을 나타냅니다.
- **A → B**: "A 태스크가 완료되어야 B 태스크를 시작할 수 있음"

**의존성 타입** (향후 확장 예정):
- **FS** (Finish-Start): A 완료 후 B 시작
- **SS** (Start-Start): A 시작 후 B 시작
- **FF** (Finish-Finish): A 완료 후 B 완료
- **SF** (Start-Finish): A 시작 후 B 완료

### 6.3 그래프 조작

**확대/축소**:
- 마우스 휠 사용

**이동**:
- 마우스 드래그로 화면 이동

**노드 클릭**:
- 노드를 클릭하면 해당 태스크의 상세 정보를 볼 수 있습니다.

## 7. 캘린더 사용법

통합 캘린더에서 모든 프로젝트의 일정을 한눈에 볼 수 있습니다.

### 7.1 캘린더 접근

**절차**:
1. 좌측 메뉴에서 **"캘린더"**를 클릭합니다.

### 7.2 캘린더 뷰

**뷰 전환**:
- **월간 뷰** (Month): 한 달 전체 보기
- **주간 뷰** (Week): 일주일 상세 보기
- **일간 뷰** (Day): 하루 일정 상세 보기

### 7.3 이벤트 타입

캘린더에 표시되는 이벤트:
- **태스크 시작일**: 태스크가 시작되는 날
- **태스크 종료일**: 태스크가 완료되는 날
- **마일스톤**: 중요한 이정표
- **Enabler 전달일**: Enabler가 준비되는 날
- **프로젝트 킥오프**: 프로젝트 시작일
- **프로젝트 마감**: 프로젝트 종료일

**색상 구분**:
각 이벤트 타입은 서로 다른 색상으로 표시됩니다.

### 7.4 이벤트 클릭

이벤트를 클릭하면 상세 정보 모달이 열립니다.

**모달 내용**:
- 이벤트 제목
- 날짜 및 시간
- 설명
- 연결된 프로젝트/태스크 링크

## 8. 리포트 기능

프로젝트 진행 현황과 문제점을 분석하는 다양한 리포트를 제공합니다.

### 8.1 리포트 메뉴

**리포트 종류**:
1. **진행 현황 리포트**: 전체 프로젝트 진행 상태
2. **크리티컬 패스 리포트**: 프로젝트 일정에 영향을 주는 주요 태스크
3. **지연 분석 리포트**: 지연된 태스크 분석

### 8.2 진행 현황 리포트

**내용**:
- **전체 통계 카드**:
  - 총 태스크 수
  - 완료된 태스크 수
  - 진행 중인 태스크 수
  - 전체 진행률 (%)
- **상태별 분포 차트** (파이 차트):
  - 대기 중, 진행 중, 완료, 보류, 차단됨, 취소 상태별 비율
- **우선순위별 분포 차트** (바 차트):
  - 낮음, 보통, 높음, 긴급 우선순위별 태스크 수

### 8.3 크리티컬 패스 리포트

**크리티컬 패스란?**
프로젝트 완료 시간에 직접적인 영향을 주는 태스크들의 연결 경로입니다. 이 경로의 태스크가 지연되면 전체 프로젝트가 지연됩니다.

**리포트 내용**:
- **크리티컬 태스크 목록**:
  - 크리티컬 패스에 속한 태스크들
  - 각 태스크의 여유 시간 (Slack): 0일 = 크리티컬
- **리스크 분석**:
  - 프로젝트 지연 위험 수준
  - 권장 조치 사항

### 8.4 지연 분석 리포트

**내용**:
- **지연된 태스크 목록**:
  - 종료일이 지났지만 완료되지 않은 태스크
  - 각 태스크의 지연 일수
- **평균 지연 일수**: 전체 지연된 태스크의 평균 지연 기간
- **Enabler 지연 영향** (구조 구현, 데이터 연동 예정):
  - Enabler 지연으로 인한 태스크 차단 현황

### 8.5 리포트 익스포트

**CSV 익스포트**:
1. 원하는 리포트 화면으로 이동합니다.
2. **"익스포트"** 버튼을 클릭합니다.
3. **"CSV"** 옵션을 선택합니다.
4. 파일이 다운로드됩니다.

**Excel 익스포트** (향후 추가 예정):
v1.1에서 지원 예정입니다.

**PDF 리포트** (향후 추가 예정):
v2.0에서 지원 예정입니다.

## 9. 자주 묻는 질문 (FAQ)

### Q1. 프로젝트를 실수로 삭제했어요. 복구할 수 있나요?

**A**: 아쉽게도 삭제된 데이터는 복구할 수 없습니다. 중요한 프로젝트는 삭제 전에 반드시 확인하세요. 정기적인 데이터베이스 백업을 권장합니다.

**백업 방법**:
- Windows: `backend/data/project_manager.db` 파일을 복사하여 안전한 곳에 보관
- Linux: 동일

### Q2. 태스크 의존성을 어떻게 설정하나요?

**A**: 현재 버전(v1.0.0)에서는 의존성 설정 UI가 제공되지 않습니다. v1.1에서 추가될 예정입니다. 현재는 API를 통해 설정 가능합니다.

### Q3. 여러 사용자가 동시에 접속할 수 있나요?

**A**: 네, 가능합니다. 그러나 현재 버전은 사용자 인증 기능이 없으므로, 같은 네트워크에 있는 모든 사용자가 접근할 수 있습니다. 동시 접속은 10명 이하를 권장합니다.

### Q4. 간트 차트에서 태스크를 드래그로 이동할 수 있나요?

**A**: 네, 가능합니다. 태스크 막대를 좌우로 드래그하면 시작일과 종료일이 자동으로 변경됩니다.

### Q5. 데이터는 어디에 저장되나요?

**A**: 모든 데이터는 `backend/data/project_manager.db` SQLite 데이터베이스 파일에 저장됩니다. 이 파일을 백업하면 모든 데이터를 보존할 수 있습니다.

### Q6. 인터넷 연결이 필요한가요?

**A**: 아니요, 완전히 오프라인으로 동작합니다. 폐쇄망 환경에서도 사용 가능합니다.

### Q7. 다크 모드를 어떻게 전환하나요?

**A**: 상단 헤더 우측의 **달/해** 아이콘을 클릭하면 라이트 모드와 다크 모드가 전환됩니다.

### Q8. 프로젝트가 너무 많아지면 성능이 느려지나요?

**A**: 1,000개 프로젝트, 프로젝트당 10,000개 태스크까지는 원활하게 동작합니다. 이를 초과하면 성능이 저하될 수 있습니다.

### Q9. 모바일에서도 사용할 수 있나요?

**A**: 기본적인 반응형 디자인이 적용되어 있지만, 최적화는 데스크톱 환경입니다. v2.0에서 모바일 최적화가 향상될 예정입니다.

### Q10. 사용자 인증 기능은 없나요?

**A**: 현재 버전(v1.0.0)에는 인증 기능이 없습니다. v2.0에서 JWT 기반 인증 및 RBAC(역할 기반 접근 제어)가 추가될 예정입니다.

## 10. 문제 해결

### 문제 1: 서버가 시작되지 않아요

**증상**: `start.bat` 또는 `start.sh` 실행 시 에러 발생

**해결 방법**:
1. Python이 설치되어 있는지 확인: `python --version` (3.10 이상 필요)
2. 가상 환경이 생성되어 있는지 확인: `backend/venv/` 폴더 존재 확인
3. 재설치: `deployment/windows/install.bat` 또는 `deployment/linux/install.sh` 다시 실행

### 문제 2: 웹 페이지가 로드되지 않아요

**증상**: 브라우저에서 `http://localhost:5173` 접속 시 "연결할 수 없음" 오류

**해결 방법**:
1. 서버가 정상 실행 중인지 확인
2. 명령 프롬프트/터미널에서 에러 메시지 확인
3. 포트 5173, 8000이 이미 사용 중인지 확인:
   - Windows: `netstat -ano | findstr :5173`
   - Linux: `lsof -i :5173`
4. 다른 프로그램이 해당 포트를 사용 중이면 종료 후 재시작

### 문제 3: 데이터가 사라졌어요

**증상**: 입력한 프로젝트와 태스크가 사라짐

**해결 방법**:
1. `backend/data/project_manager.db` 파일이 존재하는지 확인
2. 백업 파일이 있다면 복원:
   - 서버 종료
   - 백업 파일을 `backend/data/project_manager.db`로 복사
   - 서버 재시작
3. 백업이 없다면 복구 불가 (정기 백업 권장)

### 문제 4: 간트 차트가 표시되지 않아요

**증상**: 간트 차트 탭을 클릭했지만 빈 화면

**해결 방법**:
1. 프로젝트에 태스크가 있는지 확인 (최소 1개 이상 필요)
2. 브라우저 콘솔 에러 확인 (F12 키 누름)
3. 브라우저 캐시 삭제 후 새로고침 (Ctrl+Shift+R)

### 문제 5: CSV 익스포트가 한글이 깨져요

**증상**: CSV 파일을 Excel에서 열었을 때 한글이 깨짐

**해결 방법**:
1. **메모장으로 열기**:
   - CSV 파일을 메모장에서 열기
   - "다른 이름으로 저장" 클릭
   - 인코딩을 "UTF-8"에서 "ANSI"로 변경
   - 저장 후 Excel에서 열기

2. **Excel 가져오기 기능 사용**:
   - Excel 실행
   - 데이터 탭 → 텍스트/CSV 가져오기
   - 파일 선택
   - 파일 원본을 "UTF-8" 선택
   - 가져오기 완료

### 문제 6: 서버 종료는 어떻게 하나요?

**Windows**:
- 명령 프롬프트 창을 닫거나 `Ctrl+C` 입력

**Linux**:
```bash
./deployment/linux/stop.sh
```
