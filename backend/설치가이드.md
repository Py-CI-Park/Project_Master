# Backend 설치 가이드

## 문제 해결: requirements.txt 파일 누락

### 원인
이전 커밋에서 `requirements.txt`와 `requirements-dev.txt` 파일이 실수로 삭제되어 커밋되었습니다.

### 해결 완료
✅ 파일이 복구되었습니다. 이제 아래 명령어로 설치하세요.

---

## 설치 순서

### 1단계: 가상환경 활성화
```bash
cd /mnt/c/Programming/Project_Master/backend
source venv/bin/activate
```

### 2단계: 의존성 패키지 설치
```bash
pip install -r requirements.txt
```

### 3단계: bcrypt 버전 조정 (중요!)
```bash
pip install bcrypt==3.2.0
```

**주의**: bcrypt는 반드시 3.2.0 버전을 사용해야 합니다.
- passlib 1.7.4와 호환성 문제 때문
- bcrypt 4.x 또는 5.x 버전은 사용 불가

### 4단계: 추가 패키지 설치
```bash
pip install python-socketio python-engineio email-validator
```

### 5단계: 개발용 패키지 설치 (선택사항)
```bash
pip install -r requirements-dev.txt
```

## 문제 발생 시

### 오류 1: `ModuleNotFoundError: No module named 'socketio'`
```bash
pip install python-socketio python-engineio
```

### 오류 2: `ModuleNotFoundError: No module named 'email_validator'`
```bash
pip install email-validator
```

### 오류 3: bcrypt 호환성 오류
```
AttributeError: module 'bcrypt' has no attribute '__about__'
ValueError: password cannot be longer than 72 bytes
```

**해결 방법**:
```bash
pip uninstall bcrypt
pip install bcrypt==3.2.0
```

### 오류 4: 포트 8000이 이미 사용 중
```bash
# Linux/macOS/WSL
lsof -i :8000
kill -9 <PID>

# Windows
netstat -ano | findstr :8000
taskkill /PID <PID> /F
```
